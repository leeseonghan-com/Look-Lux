홈 화면에서 바로 출퇴근
앱을 열거나 로그인할 필요 없이, 홈 화면 아이콘(위젯)을 누르면 큰 출근/퇴근 버튼이 바로 뜹니다. 자정 넘어 새벽에 퇴근해도 전날 근무에 정확히 기록됩니다.
출퇴근 화면 열기 →
안드로이드 아이폰
1
위의 [출퇴근 화면 열기]를 누릅니다크롬 또는 삼성 인터넷으로 열어주세요.
2
메뉴(⋮ 또는 ≡) → '홈 화면에 추가'삼성 인터넷: ≡ → 현재 페이지 추가 → 홈 화면
크롬: ⋮ → 홈 화면에 추가 → 설치(또는 추가)
3
홈 화면에 '출퇴근' 아이콘이 생깁니다원하는 위치로 끌어다 놓으세요. 누르면 바로 출근/퇴근 버튼이 뜹니다.
💡 앱 아이콘 길게 누르기
정산관리 앱이 설치되어 있다면 앱 아이콘을 길게 누르면 출퇴근 바로가기가 나옵니다. 이것도 홈 화면으로 끌어다 놓을 수 있습니다.
방법 A · 홈 화면 아이콘 (가장 쉬움)
1
위의 [출퇴근 화면 열기]를 Safari로 엽니다
2
아래쪽 공유 버튼(□↑) → '홈 화면에 추가'
3
홈 화면의 '출퇴근' 아이콘을 누르면 바로 버튼이 뜹니다
방법 B · 위젯 한 번 누르면 즉시 기록 (단축어)
1
'단축어' 앱 → ＋ → 동작 추가 → 'URL 콘텐츠 가져오기'아래 주소를 붙여넣기 하세요.
{{ toggle_link }}

3
